##Ireland Awaits

Proyecto web desarrollado para la asignatura Programación Web.
La página fue creada con el objetivo de brindar información a estudiantes interesados en realizar intercambios académicos en Irlanda, mostrando aspectos importantes como ciudades, instituciones, cultura, vida estudiantil y consejos básicos.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
